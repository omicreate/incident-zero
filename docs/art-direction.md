# インシデント・ゼロ — 絵の方針（アートディレクション）

すべての絵は、この方針に照らして採否を決める。

## ステートメント

静かな緊張。説明しない。**文字が主役、絵は「空気」**。
絵は物語を語らず、その夜の温度だけを置く。見た瞬間の派手さより、開いた瞬間の静けさで引き込む。

## ビジュアル言語

- 明度: 黒に近い暗さが基本
- 配色: ディープブルーと黒（彩度は低く）
- 質感: 35mm フィルムの粒子、わずかなもや
- 構図: 横長、広い余白と深い影
- 人物: **顔は出さない**（不気味の谷＝作り物っぽさのいちばんの原因を避ける）。後ろ姿とシルエットだけ
- 文字・ロゴ・看板・画面の表示は、絵の中に入れない（必要な文字は画面の側で組む）

## 使い方

- 行動や出来事ごとに、場所か人物の絵を出す。夜明けに向かって少しずつ明るくする
- 動きは最小（切り替わるときに薄く入るだけ）。「動きを減らす」設定では止める
- 脅迫文・電話・メール・チャット・院内ネットの地図は、絵ではなく画面の部品として組む（読みやすく、作り物っぽくならない）

## 避けるもの

光る粒子やまぶしいグラデーションの多用／絵文字の飾り／CGっぽい光沢／ホラー調の血や派手な破壊／身代金要求の画面や攻撃手順の直接の描写。

## 作り方

各場所・各人物で2案を作り、この方針に照らして1案を選ぶ（顔がいちばん見えない案を選ぶ）→ 1600×893 の JPEG にして `public/img/` に置く → 実機のブラウザで確かめる。
