# さくら町立病院の一夜 — 設計(紙の版)

2026-10-17 / 最小版(文字だけ)を作る前の設計。数字は最小版で遊んでから直す前提の仮の値。

---

## ひとことで

夜中0時24分、町にひとつしかない病院のカルテが、全部開かなくなる。
あなたは病院のシステムを一人で見てきた事務職員。**朝8時30分の外来開始まで**に、どこまで食い止め、何を見抜き、何を選ぶか。

- 1回 **15〜25分**
- **答え(どこから入られたか など)は毎回変わる**ので、何度でも遊べる
- 最後は「ふりかえり会」で、自分の判断と実際の事件(半田病院・2021年)を見比べる

## 面白さの芯(この5つが効いているかを最小版で確かめる)

1. **時間が足りない** — 行動するたびに時計が進む。全部はできない。何をあきらめるかを選ぶ
2. **自分で見抜く** — どこから入られたか・裏口はどこか・控えは無事か・情報は盗まれたかは、調べないと分からない
3. **正解のない選択** — 全部抜けば広がりは止まるが院内の電話も止まる。電源を落とせば早いが手がかりが消える
4. **数字が結末を決める** — 広がり・患者への影響・信頼・証拠の4つ。場面の分岐ではなく、積み上げで結末が決まる
5. **あとから効く** — 朝6時に仕込まれた処理が動く、つなぎ直したら戻ってくる、盗まれた情報が後で出る

## 難易度は1つ

- 用語の説明・技術の深掘りは「開けば読める」に寄せる(最小版では本文を平易に書くことで代える)
- 毎回の「正解/不正解」は出さない。結果だけが起きる。解説は最後のふりかえり会にまとめる
- 登場人物は答えを言わない。立場ごとに違うことを言う(院長は「外来は止めるな」)

## 毎回変わる「今夜の答え」

| 項目 | 候補(毎回ランダムに1つ) |
|---|---|
| 侵入口 | VPN機器の古い弱点 / 業者の保守用の接続(どの病院も同じパスワード) / 職員に届いた偽の添付メール |
| 裏口 | 新しく作られた管理者ID / サーバに常駐する遠隔操作の道具 / 毎朝6時に動く予約された処理 |
| バックアップ | 事件の前から暗号化されていた / 無事だが院内ネットにつながっている / 院内は全滅、金庫に1週間前の外付けディスク |
| 持ち出し | あり / なし(はったり) |

**ひっかけ**: VPN機器が古いこと、業者のパスワードが使い回しなことは、**どの回でも本当**。「弱点がある」と「そこから入られた」は別。調べた記録に「使われた跡」があるかで見分ける。

## 4つの数字

| 数字 | 始まり | 動き方 |
|---|---|---|
| 広がり(院内の暗号化) | 10% | つながったまま 14%/時 → 外だけ切る 8%/時 → 部署ごとに分ける 2%/時 → 全部抜く 0。サーバの電源を落とすと 約1/3 に |
| 患者への影響 | 0 | 紙の準備なし 5/時、準備済み 1/時。線を全部抜くと院内の電話・検査機器も止まり、さらに増える |
| 信頼 | 50 | 警察・院長・県への報告、職員への連絡、記者への答え方、支払いで動く |
| 証拠 | 80 | 電源を落とす・作り直す・職員がPCをつける と減る。保全すると守られる |

**バックアップの時限**: 「無事だが院内ネットにつながっている」回では、外か院内の線がつながったまま広がりが35%を超えると、**知らないうちに**暗号化される。早く線を抜くか、確かめるか。

## 結末とふりかえり会

- 点数は内訳つき(100点): 患者を守る35・広がりを止める15・信頼20・証拠を残す10・見抜く20。見抜くは、侵入口を使われた跡で見抜いて塞げば8(当てずっぽうで塞いだだけなら3)、裏口を消せば8、控えを守れば4
- 減点: 戻ってきた -25、身代金を払った -10、正体の分からない会社に払った -5。S 80以上 / A 65以上 / B 45以上 / C
- 出来事は、手が離せないと対応が遅れる(画面に「1:50 の内線(手が離せず、2:19 に対応)」と出る)。外来までに終わらない行動は選べない
- **つなぎ直したのに侵入口か裏口が残っていたら「戻ってきた」**(最悪の結末)
- 後日談: 診療がITで戻るまでの週数、盗まれた情報が出たときの町の反応、支払いの行方、報告書に侵入経路を書けたか
- ふりかえり会
  - 今夜の答え(侵入口・裏口・控え・持ち出し)と、あなたが見抜けたか
  - 分かれ目(外を切った時刻、紙が整った時刻、院長に伝えた時刻、対応チームに電話した時刻、証拠)
  - あなたの夜(時系列)
  - 実際の事件では(半田病院・2021年の公表された事実)

## 安全の線(本物らしさを上げても守る)

- 出してよい: 公表された報告にある事件の流れ・時刻・被害、架空の記録(ログ)の見た目、架空のID名
- 出さない: 実在のコマンド、設定値、弱点を突く具体的なやり方、実在の脆弱性番号
- 病院・人物・会社はすべて架空と明記する

## 最小版の状態(2026-10-17)

- ファイル: `prototype/index.html`(ブラウザで開けば遊べる。サーバ不要)
- バランス確認: `prototype/sim.mjs`(`node sim.mjs 400` で、遊び方ごとに400回ずつ自動で遊ばせる)

自動で遊ばせた結果(各400回)

| 遊び方 | 平均点 | S | A | B | C |
|---|---|---|---|---|---|
| 何もしない | 16 | 0% | 0% | 0% | 100% |
| でたらめ | 33 | 0% | 2% | 33% | 65% |
| あわてる(電源を落とし、全部抜き、記者に否定、朝はつなぐ) | 0 | 0% | 0% | 0% | 100% |
| 慣れているが推理しない(入口を全部塞ぐ) | 76 | 8% | 92% | 0% | 0% |
| 慣れていて推理する | 79 | 44% | 57% | 0% | 0% |
| 答えを知っている(上限の目安・部署ごとに分ける) | 80 | 68% | 32% | 0% | 0% |
| 答えを知っている(上限の目安・全部抜く) | 79 | 7% | 93% | 0% | 0% |

- 慣れた人でも「待つ」はほぼ使わない。県への報告や持ち出しの調査は、約7割の回で時間切れになる(全部はできない)
- 推理すると S が増える(8% → 44%)。当てずっぽうより見抜くほうが報われる
- 「全部抜く」と「部署ごとに分ける」は平均点がほぼ同じ。紙の準備が先に整っていれば全部抜くほうが有利、という迷いどころになっている
- 1回の判断は約28回(15〜25分の見込み)

## 次に直したいこと(最小版で気づいたもの)

- スマホでは「わかったこと」が画面のいちばん下になる。推理の材料なので、上に出すか、たたんで近くに置く
- 救急の内線に長く応えられなかったとき、救急車がもう着いている、という結果にしたい(いまは待ってくれる)
- 裏口が予約処理の回で、6時より前に「動いているもの」を調べ終えるのが難しい。面白い緊張か、理不尽かを遊んで判断する
